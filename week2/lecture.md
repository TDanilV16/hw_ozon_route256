Программа -- набор инструкций для CPU

Есть процессы и потоки. В потоке выполняются инструкции. У каждого потка есть свои переменные и своя память.
Потоки могут работать с общей памяти, которая выделена в рамках процесса.
Процесс про ресурсы, поток про исполнение.

Синхронное выполнение -- последовательно выполняем инструкции одного потока на одном CPU

Параллельное выполнение -- на нескольо CPU разгружаем части. На 2 потоках. 
Сложные вычислительные части выгодно запускать на нескольких CPU

Асинхронное выполнение -- часть инструкций (чтение) на одном потоке, обработка на другом потоке. 
Утилизируем вычислительные мощности потока тогда, когда он простаивает. Это происходит за счет переключения контекста.
Это недешевая операция.

Горутина -- примитив исполнения программы в go. Есть go runtime, которая работает поверх абстракций ОС. 
Управляет горутинами. 

go data race checker. Обнаруживает состояние гонки.

waitGroup -- нужен для синхронизации. Блокирует горутину. 

wg.Add(n) n -- число работ, которые мы должны ожидать.
wg.Done() -- выполена горутина
wg.Wait() -- блокируем горутину и ждем, пока все работа не будет выполена

```go
func main() {
	var wg sync.WaitGroup

	var counter int

	wg.Add(1)

	go func() {
		defer wg.Done()
		counter++
	}()

	wg.Wait()

	counter++
}
```

rwmutex -- чуть круче мьютекса
lock -- блокирует lock и rlock. Блокировка на запись
rlock -- блокирует только lock. Блокировка на чтение. Две горутины могут читать конкурентно

Каналы -- обеспечивает общее пространство для горутин. Через каналы можно перекидывать данные между горутинами
Примитив безопасной передачи данных между горутинами.

```go
func main() {

	var counter int

	counterCh := make(chan int)

	go func() {
		counterCh <- 1 // ожидание чтения из канала
	}()

	counter = <-counterCh // ожидание записи в канал

	fmt.Println(counter)
}
```

close -- закрыть канал. Теперь чтение из канала выдает zero-value. Писать туда нельзя
Можно сделать for range -- читай из канала, пока он не закрыт.

select -- есть два канала, из которых мы можем читать/писать.
